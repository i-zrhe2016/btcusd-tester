# Vue Web 应用

## 职责

前端使用 Vue 3 Composition API、TypeScript 和 Vite。它负责复盘项目管理、K 线回放和手动 Buy/Sell/平仓交易记录，不在浏览器计算聚合或交易信号。

## 页面结构

单页工作台采用两个明确视图，避免把建项和复盘操作挤在同一个页面：

1. `项目` 视图：创建复盘项目、设定品种、周期、UTC 复盘时间范围和播放速度，并列出已保存项目。
2. `复盘` 视图：打开当前项目后进入应用视口级全屏 K 线窗口，提供周期切换、播放、播放中速度调整、Buy/Sell、平仓和当前进度/持仓状态；进入该视图需要已登录。

登录后创建新项目或选择已有项目会进入 `复盘` 视图。未登录时只能停留在 `项目` 视图，创建、保存和打开复盘项目的动作会被拦截。复盘页的 K 线区域必须占满除顶部导航外的剩余应用视口；项目标题和时间范围放在底部状态栏摘要中，不能遮挡图表主体。底部状态栏固定为小长条浮层，显示项目、周期、播放、Buy/Sell、平仓和进度/行情状态；平仓按钮仅在当前持仓时可用，不提供展开面板；图表为状态栏预留高度，避免遮挡 Stoch 副图与时间轴。页面不得产生横向滚动。

复盘项目草稿、已保存项目和手动交易记录保存在浏览器 `localStorage`，刷新后保持状态；Buy/Sell 按固定数量记录，平仓按钮按当前持仓数量一次性平多或平空；行情数据仍以服务端 API 为准。
创建、保存或恢复项目时，如果时间范围超出行情元数据的覆盖范围，前端会自动调整到最新可用区间，并清除无法迁移的旧交易与绘图状态。

## 图表约定

- K 线使用黑白样式：纯黑色背景上，上涨为白色空心实体，下跌为白色实心实体，并保留文字/位置等辅助信息，不只依赖颜色表达方向。
- 图表绘图区使用纯黑色背景，坐标轴、蜡烛和交易标记使用高对比浅色；复盘窗口不显示网格线或贯穿全图的最新价参考线。
- 回放时按游标只显示已播放的 K 线，暂停后仍保留当前游标。
- 复盘页支持切换周期；切换后以当前 K 线时间戳为锚点重新加载同一项目时间范围内的新周期 K 线，保留复盘进度并清空旧周期下的手动交易标记。
- 每次请求最多 60 根，接口硬上限 5,000 根；当前窗口只剩 15 根未播放时后台预取下一窗口，超过当前窗口时通过按需加载继续追加。
- 复盘图表在 K 线下方显示 Stoch 双组 K/D 副图，四条曲线按白、黄、红、青配色，不绘制 20/50/80 等固定参考线。点击右上角 Stoch 可调整当前周期 K1/K2、应用或恢复默认；参数按周期保存在 `btcusd.stoch.parameters.v1`，刷新后保留。
- 图表关闭 Lightweight Charts 的 TradingView 图标（`layout.attributionLogo: false`），改为在页面底部展示 `TradingView Lightweight Charts™` 署名与 `https://www.tradingview.com/` 链接，满足库许可证的署名要求；移除页脚署名前必须保留图表图标。
- Stoch 使用收盘价的滚动最低/最高值，区间为零时原始 K 为 50；平滑长度为 `max(1, round(length × 0.3))`，K/D 依次进行 SMA。只计算已播放行情，极值窗口使用当前可用历史，SMA 满足窗口前不绘制；当前加载窗口起点之前的历史不参与计算，因此窗口较短时与拥有更长历史的 TradingView 图表可能不同。
- 支持 1m、5m、15m、30m、1h、2h、3h、4h、1d、1w、1M；Stoch 默认 K1/K2 依次为 10/20、30/180、30/120、30/120、30/120、30/120、45/180、30/210、10/70、10/40、10/30。
- 复盘图表使用 `@getcandlekit/charts` `0.1.0` 提供 TradingView 风格的绘图交互。左侧垂直工具栏按“线条 / 形状 / 测绘”分组，支持趋势线、射线、延长线、水平线、水平射线、垂直线、十字线、箭头、矩形、椭圆、三角形、平行通道、价格区间、日期区间、Fib 回撤和 Fib 扩展；选择工具后在图表上按 CandleKit 的锚点数量点击完成绘制。
- 绘图属于当前复盘项目，由应用项目模型统一写入 `localStorage`；CandleKit 的私有绘图存储已关闭。默认绘图为黄色 2px 实线且不填充；选择工具后可拖动图形或锚点，支持锁定、删除选中图形、清除全部绘图和 `Esc` 取消草稿；在图表上点击右键会弹出“删除全部绘图”菜单。按住 `Shift` 在图表上拖动可使用测量尺，显示价格、百分比、K 线数量和时间差。
- 当前已加载/已播放 K 线右侧会保留一批不绘制实体的未来时间槽，绘图工具可在这段未加载区域落点；锚点按时间戳保存，后续行情追加后会自动与新 K 线对齐。
- 项目存储使用 `btcusd.replay.projects.v2`。从 v1 恢复时保留项目、游标和交易记录，但旧版趋势线不迁移；旧 v1 数据保留不覆盖，后续保存写入 v2。
- 底部浮层始终展示当前游标的进度、时间和复盘状态。
- 播放速度支持在复盘播放中直接调整，范围为 `0.25x` 至 `8x`，步进为 `0.25x`；调整后立即重建播放定时器并保存到当前项目。
- 时间轴和表单一律标记 UTC。

## 状态管理

不引入全局状态库。页面使用组合式函数分别管理：

- `replay`：项目、当前项目、快照、播放游标、播放状态和速度。
- `trades`：当前项目的手动交易、持仓、已实现盈亏、浮动盈亏和最近成交。
- `health`：元数据、加载状态和错误提示。
- `auth`：Clerk 加载状态和当前会话是否已登录，用于保护复盘视图入口。

复盘项目、当前项目、最后选中的视图和手动交易记录保存在浏览器本地。

## Clerk 认证

前端使用 `@clerk/vue` 提供登录、注册和账户管理 UI。`frontend/src/main.ts` 在应用入口注册 `clerkPlugin`，Publishable Key 通过 `VITE_CLERK_PUBLISHABLE_KEY` 注入；该变量可以出现在浏览器构建产物中，但 `CLERK_SECRET_KEY` 不得放入前端代码或 `VITE_` 变量。

顶栏在 Clerk 加载完成后显示以下状态：

- 未登录：显示“登录”和“注册”按钮，使用 Clerk 的 modal 预置流程。
- 已登录：显示 `UserButton`，可打开账户管理菜单并退出登录。

未登录时复盘入口、项目创建/保存/选择和从 `localStorage` 恢复复盘视图都会被前端会话 guard 拦截；登录后才允许进入复盘。该 guard 只保护当前前端界面，不把复盘项目从 `localStorage` 迁移到服务端，也不改变行情和回测 API 的鉴权边界。后续如果需要按用户隔离项目或保护 API，应单独增加服务端会话校验和数据归属设计。

## 交互与可访问性

- 所有输入使用可见 `label`，错误显示在对应字段附近。
- 异步提交期间禁用按钮并显示明确进度；失败信息包含原因和重试操作。
- 所有按钮可通过键盘操作，焦点环清晰；触控目标至少 `44×44px`。
- 正文对比度至少 `4.5:1`，数据线和控件边界至少 `3:1`。
- 遵循 `prefers-reduced-motion`，不使用阻塞式或纯装饰动画。
- 页面提供跳到主要内容的链接，标题层级连续，状态更新使用礼貌型 live region。

## API 访问

浏览器只使用同源相对路径 `/api/...`，不感知容器名或内部端口。前端不得持有 PostgreSQL、行情服务或其他服务凭据。前端登录状态不等同于 API 已完成服务端鉴权。

## K 线按需加载

复盘项目的时间范围可以大于单次浏览窗口。页面首次只请求最多 60 根 K 线，并在控制台显示当前已加载数量；当前游标距离已加载窗口末尾不超过 15 根时，后台预取后续窗口，播放继续使用已有数据。用户点击“加载更多 K 线”时也会请求后续窗口；播放到当前窗口末尾时，如果请求已完成则自动继续，如果请求仍在进行则等待，加载失败则暂停并提供重试按钮。新窗口按时间戳去重、排序后追加，且不重置当前游标。

切换周期时，页面保存当前游标 K 线的 UTC 时间戳，在新周期中定位到该时间点之前最近的一根 K 线；首个新周期窗口围绕该时间点加载，因此不会把进度重置到项目开头，也不会预加载完整项目范围。

行情数据刷新后，如果浏览器保存的项目时间范围超出服务端当前覆盖范围，页面会将该项目调整到可用范围，避免旧的 `localStorage` 项目导致空图。
