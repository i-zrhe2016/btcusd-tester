# K 线图表加载显示验证

范围：首次打开/恢复复盘、切换周期、新增分屏、图表首帧、后台刷新和请求失败。模式：normal + browser；级别：regression。执行方式：主会话自验证；探索代理只做只读定位，没有执行验收。

结果：本地构建、31 项相关测试及模拟行情浏览器流程通过。真实行情服务未在此次验证中运行，不代表生产环境端到端验收。

## 验收与证据

| 验收要求 | 风险 | 已执行证据 | 结果 |
|---|---|---|---|
| 初次/恢复打开不露出空黑画布 | 请求及组件加载期间没有内容 | 浏览器暂停 snapshot 响应后恢复双屏：两屏均有浅色、不透明加载面板，尚未创建行情画布 | 通过 |
| 周期切换等待态有内容 | 卸载旧图后出现空黑区 | 浏览器暂停请求，主屏切到 1h：面板背景 rgb(241,240,234)、opacity 1，提示“正在加载行情” | 通过 |
| 首帧准备完成前持续遮挡 | API 完成早于绘制 | 组件测试：第一帧仍有遮罩，第二帧后才移除；零尺寸时继续覆盖；卸载取消回调 | 通过 |
| 新增分屏等待时有内容 | 副屏等待主时钟或请求 | 浏览器新增双屏：副屏为浅色加载面板，主屏保留 11 个画布；释放请求后两屏 aria-busy=false | 通过 |
| 后台刷新不隐藏已有图表 | 重新加载造成闪屏 | 组件测试：loading 来回切换时容器保持挂载、控制器和可见范围保留；已就绪图表不重新盖住 | 通过 |
| 加载失败不是空黑图 | 错误状态不可恢复 | 组件测试及浏览器模拟副屏离线：浅色错误面板显示错误内容，并有原有重试入口，主屏继续显示 | 通过 |
| 手机窄屏等待态保持覆盖 | 响应式尺寸改变 | 375px 浏览器切至 15m：两屏面板背景浅色且 opacity=1；测试后已清除尺寸模拟 | 通过 |
| 取消整图淡入 | 透明图层露出空底 | 移除整图淡入 class/样式；组件测试断言无 chart-timeframe-enter；保留周期按钮滑动高亮 | 通过 |
